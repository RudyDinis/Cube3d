# Cub3d


## Description
Cub3d is a projet where you have to do a game with raycasting like wolf3d in C.
The goal is to learn, event, shapes, colors in MLX.

## Instructions
1. you must have the mlx_lib
   - make
     - ./Cub3d maps/mapyouwant.cub
